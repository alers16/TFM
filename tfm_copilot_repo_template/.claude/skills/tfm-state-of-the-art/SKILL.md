# Objetivo
Ayudar a construir el estado del arte (Antecedentes) del TFM de forma rigurosa y útil para la
memoria, situando los antecedentes y mostrando un estudio comparativo (requisito de la guía UMA).

# Cuándo usar esta skill
- Cuando el usuario pida revisar literatura.
- Cuando haya que estructurar el capítulo de estado del arte.
- Cuando haya que clasificar afirmaciones en seguras, dudosas o pendientes de verificar.

# Reglas
- No inventes referencias.
- No cambies las RQ oficiales.
- No conviertas el tema en otro distinto.
- Distingue entre evidencia consolidada, evidencia parcial e hipótesis de trabajo.
- Aporta valor añadido: no debe ser una mera recopilación de técnicas.

# Salida esperada
- Resumen ejecutivo corto.
- Estructura del capítulo.
- Lista de afirmaciones que requieren fuente.
- Lista de huecos de investigación pendientes de comprobar.
