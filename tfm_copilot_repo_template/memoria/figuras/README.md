# Figuras y diagramas de la memoria

Estructura:

- `src/` — fuentes editables (Mermaid `.mmd`, GraphViz `.dot`, etc.).
- `img/` — renderizados (`.svg`, `.png`) usados en la memoria final.

Catálogo y propósito de cada figura: ver [../PLAN_VISUAL.md](../PLAN_VISUAL.md).

## Convención de nombres

`figXX-slug.mmd` / `figXX-slug.svg`, donde `XX` es el ID de la figura (p. ej. `fig41-arquitectura-paquetes.mmd`).

## Estado

Vacío. Las figuras se generarán a medida que se redacten los capítulos correspondientes.
